# 🧠 Brain-Sprint

**Brain-Sprint** is an interactive, AI-powered productivity and learning platform designed to streamline task tracking, automated reminder scheduling, interactive quizzes, and dynamic progress reporting.

---

## 🌟 Key Features

* **Interactive Dashboard:** Built with Streamlit for a smooth and responsive user experience.
* **Smart Data & Time Entry:** Effortlessly log tasks, study sessions, and track daily progress.
* **Automated Reminders:** Integrated backend scheduler engine to manage email notification triggers.
* **AI Diagnostic & Quiz Engine:** Dynamic quiz generation and automated reporting using Google Gemini API.
* **Cloud Database Sync:** PostgreSQL integration (via Neon DB) for reliable data persistence.

* **Frontend Framework:** Python, Streamlit

* **AI Engine:** Google Gemini Flash API
* **Automation & CI/CD:** GitHub Actions, Python `schedule` / Background Workers
* **Version Control:** Git & GitHub
